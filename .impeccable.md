## Design Context

### Users
People landing on the repository or the GitHub Pages handoff page, usually to find the live Tabellenrechner, inspect the source, or understand where the production app runs. They are likely football-statistics enthusiasts, maintainers, or curious visitors who want the actual app fast.

### Brand Personality
Precise, editorial, sporty, and pragmatic. The page should feel like a sharp match sheet, not a generic startup landing page. The emotional goal is confidence: this project is alive, maintained, and easy to route to the correct place.

### Aesthetic Direction
Dark editorial sports layout with a clear live-status hierarchy, strong typography, cream-on-ink contrast, and a restrained red accent. The page should feel like a premium club bulletin or a printed match program translated into the browser.

### Design Principles
- Make the live app CTA the primary action.
- Explain the static-vs-live split clearly and quickly.
- Keep the layout responsive, compact, and readable on mobile.
- Use strong contrast and deliberate spacing instead of generic card stacks.
- Favor a distinctive, sports-editorial mood over a generic product splash page.
